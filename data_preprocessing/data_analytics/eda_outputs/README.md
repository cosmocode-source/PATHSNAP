# EDA outputs (committed copy)

`../outputs/` is git-ignored, so these files are a committed copy of what `../PathSnap_EDA.ipynb` writes (tables, figures, Folium map),
regenerated by running the notebook from the repository root ("Restart and Run All"). They are the evidence for the EDA section of the
technical report: dataset inventory, validity checks, timestamp gaps, correlation of candidate features, network pilot, candidate-radius pilot,
label-rule pilot, train vs student shift, and an interactive Folium map of one training trip.

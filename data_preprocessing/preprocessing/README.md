# Preprocessing

Use this folder for the reusable data-preparation pipeline used by model training and inference.

Planned work:

- Read `.track`, `.nodes`, `.arcs`, and `.route` files.
- Validate and clean raw observations.
- Handle timestamps and GPS gaps.
- Generate road-segment candidates.
- Create and transform model features.
- Save preprocessing configurations and outputs.
- Record preprocessing choices and justifications in `answers.md`.
